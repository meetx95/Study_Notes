## About JavaScript

JavaScript (JS) is a high-level, lightweight, interpreted programming language used to make websites interactive and dynamic.

It is one of the core technologies of web development, along with HTML and CSS.
Main technologies of web development
Technology Purpose
HTML Creates website structure
CSS Designs and styles the website
JavaScript Adds functionality and interactivity

Example:

- HTML – Creates a button.
- CSS – Changes the button's color.
- JavaScript – Performs an action when someone clicks the button.
  Features of JavaScript

1. Lightweight programming language.
2. Dynamically typed language.
3. Object-based and prototype-based.
4. Supports event handling.
5. Supports asynchronous programming.
6. Runs in web browsers.
7. Can be used for frontend and backend development.
8. Supports functional and object-oriented programming.

JavaScript was created by Brendan Eich in 1995 while working at Netscape Communications.
